## 概要 (要約)
<!-- AUTO:START purpose=summary-1-paragraph -->
Claude Code は、プロジェクトディレクトリで `claude` コマンドを実行するだけで起動できる、対話型の AI コーディング支援 CLI ツールです。macOS・Linux・Windows いずれでも公式スクリプトや Homebrew・WinGet でインストールでき、初回起動時に Claude Pro/Max/Team または Console アカウントでログインします。自然言語の指示でコードの読解・編集・バグ修正・テスト作成・リファクタリングなどを依頼でき、変更前には必ず確認が求められます。`claude -c` で直前の会話を引き継ぎ、`claude -r` で過去セッションに再接続するほか、`/help` でコマンド一覧、`/clear` で会話履歴をリセットできます。
