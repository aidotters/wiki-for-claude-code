## 概要 (要約)
<!-- AUTO:START purpose=summary-1-paragraph -->
Claude Code は CLI ツールとして配布され、`curl install.sh` のネイティブインストーラに加え Homebrew / WinGet / apt / dnf / apk / npm の各経路から導入できる。npm 経路は Node.js 18 以上を必要とし、`@anthropic-ai/claude-code` パッケージを利用する。macOS / Linux / Windows（WSL）に対応し、初回起動時に Anthropic アカウントによる認証またはサブスクリプション / API キー設定を行う。
