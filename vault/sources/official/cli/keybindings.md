## 概要 (要約)
<!-- AUTO:START purpose=summary-1-paragraph -->
Claude Code の対話 UI は基本的なキーバインドで操作できる。`Esc` で実行中アクションの中断、`Ctrl+C` で入力クリアまたは強制終了、`↑` / `↓` で履歴遷移、`Tab` で補完、`Shift+Enter` または末尾の `\` で複数行入力が可能。`~/.claude/keybindings.json` を置くと一部ショートカットを差分上書きでカスタマイズでき、貼り付け時の改行扱いなど環境依存の挙動を調整できる。
<!-- AUTO:END -->
