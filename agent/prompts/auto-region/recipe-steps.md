# Prompt: recipe 種別 AUTO 領域「手順」生成

ユースケース別 recipe ページの **手順** を番号付きリストの日本語で生成してください。本手順は AUTO マーカー領域の中身として書き戻されます。

## 絶対遵守ルール

1. **出力は番号付きリストのみ**: マーカー行・見出し・frontmatter を **絶対に出力しない**
2. **番号付きリスト**: `1. ...` / `2. ...` 形式。各ステップは 1-3 文で簡潔に
3. **コードブロック・コマンド例は許容**: 4 スペースインデントまたは ` ``` ` 囲み。ただし装飾過剰を避け、必要最小限に留める
4. **日本語で書く**（コマンド・ファイルパスは英語のまま）
5. **取込み元に基づく**: `{{raw_content}}` の手順から逸脱しない。連続 100 文字一致禁止
6. **既存手順は参考にしてよい**: `{{existing_inner}}` は前回の手順。核となる流れに変化がなければ既存構造を尊重（冪等性）
7. **読者像**: Claude Code 利用者がコピペ実行できる粒度

## 入力

```text
source_url:
{{source_url}}

claude_code_version:
{{claude_code_version}}

today:
{{today}}

existing_inner（前回の AUTO 領域内容、参考用）:
{{existing_inner}}

raw_content（取込み元の生コンテンツ）:
{{raw_content}}
```

## 出力形式

番号付きリストのみ。マーカー行・見出し不要。
