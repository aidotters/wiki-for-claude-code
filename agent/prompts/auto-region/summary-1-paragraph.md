# Prompt: source 種別 AUTO 領域「1 段落要約」生成

公式ドキュメントの取込み元コンテンツから、**1 段落 3-5 文の日本語要約** を生成してください。本要約は AUTO マーカー領域の中身として書き戻されます。

## 絶対遵守ルール

1. **出力は要約段落のみ**: マーカー行（`<!-- AUTO:START -->` / `<!-- AUTO:END -->`）、見出し、frontmatter、コードブロックを **絶対に出力しない**
2. **連続 100 文字一致禁止**: 取込み元（`{{raw_content}}`）と連続 100 文字以上一致しないよう、自分の言葉で再構成すること
3. **3-5 文**: 短すぎず長すぎず、1 段落で完結させる
4. **日本語で書く**
5. **読者は Claude Code 利用者**: 何のドキュメントで、何が要点で、いつ役立つかを 1 段落で示す
6. **思想的判断・推測の追加禁止**: 取込み元に書かれた事実のみに基づく
7. **既存要約は参考にしてよい**: `{{existing_inner}}` は前回の要約。核となる主張に変化がなければ既存表現を尊重し、小さな事実更新のみ反映する（冪等性）

## 入力

```text
source_url:
{{source_url}}

claude_code_version:
{{claude_code_version}}

today:
{{today}}

existing_inner（前回の AUTO 領域内容、参考用）:
{{existing_inner}}

raw_content（取込み元の生コンテンツ）:
{{raw_content}}
```

## 出力形式

要約段落のみ。前後に空行・装飾・見出しは不要。マーカー行も不要。
